    Get Keycloak client secret and user password from the k8s Secret created by 03-04's configure-keycloak.sh:
    CLIENT_SECRET=$(oc get secret keycloak-client-secret-mcp-gateway -n otel25-gateway -o jsonpath='{.data.CLIENT_SECRET}' | base64 -d)

    Get test token:
    TOKEN=$(curl -s -X POST "https://$KEYCLOAK_HOST/realms/mcp/protocol/openid-connect/token" -d "grant_type=password&client_id=mcp-gateway&client_secret=$CLIENT_SECRET&username=mcp-agent&password=$USER_PASSWORD" | jq -r '.access_token')

    if [ -z "$TOKEN" ] || [ "$TOKEN" = "null" ]; then

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External MCP client -> RHCL gateway | Untrusted JSON-RPC requests requiring JWT authentication |
| RHCL gateway -> backend MCP servers | Trusted in-cluster routing via HTTPRoute + Service |
| RHCL gateway -> Keycloak | JWT token validation via OIDC discovery |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | Unauthorized tool invocation via gateway | mitigate | AuthPolicy JWT validation on mcp listener (spec.rules.authentication.jwt-auth) rejects requests without valid JWT |
| T-03-02 | Elevation of Privilege | Tool-level privilege escalation | accept | Full CEL-based per-tool authorization is optional for WG training pipeline; auth-only (D-08) is configured. All authenticated users can invoke all tools. |
| T-03-03 | Information Disclosure | Tool enumeration by unauthorized users | mitigate | AuthPolicy blocks unauthenticated tools/list requests; MCPVirtualServer filtering further limits tool visibility per domain |
| T-03-06 | Elevation of Privilege | Token replay after role revocation | accept | WG training pipeline scope; Keycloak access token lifespan (default 5 min) limits replay window. Not a production concern. |
| T-03-SC | Tampering | RHCL CRD definitions from redhat-operators | accept | Red Hat's official operator catalog is a trusted source |
</threat_model>
