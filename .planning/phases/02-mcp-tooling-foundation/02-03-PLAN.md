    2. Verify the spec file exists at the path from --spec argument (not from the allowlist config -- the allowlist's spec_path field is for baking into the generated scaffold)

    Section A -- Header: auto-generated comment with spec filename, allowlist filename, generation timestamp, and curation guide (edit descriptions in customize_components, adjust route_maps, or replace from_openapi with explicit @mcp.tool decorators; do NOT edit the ConfigMap watcher section).

    Section B -- Imports: os, json, threading, pathlib.Path, fastmcp.FastMCP, fastmcp.server.providers.openapi.RouteMap, fastmcp.server.providers.openapi.MCPType, fastmcp.server.providers.openapi.OpenAPITool, httpx.

Uses simple mtime comparison (NOT inotify, NOT watchdog) because Kubernetes ConfigMap volumes use atomic symlink swaps that break inotify watchers (per RESEARCH.md Pitfall 4).

    Section D -- OpenAPI server setup: SPEC_PATH as Path pointing to the vendored spec file (path baked from --spec argument, resolved relative to the generated file). route_maps list generated from allowlist.operations: each OperationFilter becomes RouteMap(path=op.path, methods=op.methods, mcp_type=MCPType.{op.mcp_type}), followed by a catch-all RouteMap(mcp_type=MCPType.EXCLUDE). customize_components(route, component) stub function with a pass body and a comment for Phase 3 curation. httpx.AsyncClient with base_url from get_backend_url(). FastMCP.from_openapi() call with openapi_spec, client, route_maps, and mcp_component_fn=customize_components.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ConfigMap volume mount -> generated MCP server | Backend URL injected via file; malformed values could redirect traffic |
| OpenAPI spec file -> from_openapi() parser | Untrusted spec could produce unexpected tool definitions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | ConfigMap watcher in generated scaffold (_load_backend_url) | mitigate | URL format validation: reject values not starting with http:// or https://; keep previous valid URL on invalid input. test_rejects_invalid_url verifies this. |
| T-02-SC | Tampering | PyPI installs (fastmcp, httpx, pyyaml, pydantic) | accept | All packages verified in Plan 01 checkpoint (Task 1). No new unverified packages introduced. |
</threat_model>
