<objective>
Enrich vendored OpenAPI specs with realistic telecom example values so Prism mock backends return domain-appropriate data instead of Lorem Ipsum (D-16).

Purpose: Prism's dynamic mock generator uses json-schema-faker on properties that lack explicit example values, producing nonsensical strings like "sunt sit" for nsiId and negative numbers like -60465668 for loadLevelInformation. Adding realistic example values at the schema property level makes Prism return telecom-realistic responses, which is essential for SDG training data quality.
Output: Five enriched spec files with schema-level example values pulled from TM Forum user guides and 3GPP standards.
</objective>
